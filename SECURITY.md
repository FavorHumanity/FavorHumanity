# Security Policy

This is my profile repository. It contains no code or user data.

## Reporting a vulnerability

Please **do not open a public issue**. Email **favortaueva@gmail.com** with "Favor Figota Taueva security" in the subject. Include what you found, where (file and commit), and how to reproduce it. I aim to acknowledge reports within 7 days.

## Scope

This profile README. For a project, use the SECURITY.md in that project's repository.
